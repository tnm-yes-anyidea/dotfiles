# Neovim Keybindings Reference

## General & Navigation
| Key | Action |
| :--- | :--- |
| `<C-b>` | Toggle Sidebar (NvimTree) |
| `<C-p>` | Find Files (Fzf-lua) |
| `<F1>`  | Command Palette |
| `<C-t>` | Open terminal/close terminal inside nvim |
## Git
| Key | Action |
| :--- | :--- |
| `<leader>gg` | Open Lazygit |
| `<F7>` | Open Lazygit |

## LSP (Available in LSP-enabled buffers)
| Key | Action |
| :--- | :--- |
| `gd` | Go to Definition |
| `K` | Hover Documentation |
| `<leader>ca` | Code Action |
| `<F2>` | Rename symbol |
| `<leader>f` | Format buffer |

## DAP (Debugger)
| Key | Action |
| :--- | :--- |
| `<F3>` | Debug: Continue |
| `<F4>` | Debug: Toggle UI |
| `<F5>` | Debug: Run Last |
| `<F6>` | Debug: Add Watch |
| `<F8>` | Debug: Toggle Breakpoint |
| `<F10>` | Debug: Step Over |
| `<F12>` | Debug: Step Into |
| `<S-F12>` | Debug: Step Out |
